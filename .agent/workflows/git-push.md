// turbo-all

1. Check git status
```bash
git status --short
```

2. Stage all changes
```bash
git add -A
```

3. Commit with a descriptive message (generate based on changed files)
```bash
git commit -m "<generated commit message>"
```

4. Push to remote
```bash
git push
```
