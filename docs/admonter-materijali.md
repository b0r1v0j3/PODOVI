| Skraćenica | Značenje |
|---|---|
| DGP / TGP 1L | tip daske (jednolamelna landhausdiela) |
| ČETKAN | brushed / gebürstet |
| EC ULJE (i 'OLJE') | Admonter **natur geölt easy care** finiš |
| MAT LAK | matt lackiert / matt versiegelt |
| 5G / LOC-IT | Admonter **lock-it** klik profil |
| SB | **Softwood-Backing** (donji sloj meko drvo; izvor: Walnut datasheet) |
| ONDFRI / ONDKAR | **OndO by Admonter** linija (ugašen pod-brend; dekori Frijo/Kari sada u glavnom 13mm lock-it programu) |
| VIVID / PLACID / CALM | OndO gradacije = rustic / basic / elegance |
